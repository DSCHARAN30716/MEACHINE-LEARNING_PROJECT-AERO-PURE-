# Separate Week Programs

Run each week independently from the project root.

## W1

```powershell
python week_01_target_eda.py
```

Creates W1 EDA and target-framing reports in `outputs/`.

## W2

```powershell
python week_02_ingest_clean_pipeline.py
```

Creates W2 ingestion, validation, feature-audit, and model-ready preview reports in `outputs/`.

W1 handles target framing and first EDA. W2 handles ingestion, cleaning, validation, and the leakage-safe preprocessing pipeline.
